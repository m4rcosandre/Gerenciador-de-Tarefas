# Gerenciador de Tarefas
Gerenciador de Tarefas

Gerenciador de Tarefas (To-Do List) via Linha de Comando (CLI)

Um projeto desenvolvido em Python para gerenciar tarefas diárias diretamente pelo terminal. Este aplicativo demonstra domínio sobre estruturas de dados fundamentais, manipulação de arquivos JSON para persistência de dados e lógica de programação para operações CRUD.

Funcionalidades:

O programa permite ao usuário:
- Adicionar tarefas com uma breve descrição.
- Listar todas as tarefas, mostrando o status de conclusão.
- Concluir tarefas pelo número (índice), alterando seu status para [x].
- Remover tarefas pelo número (índice).
- Salvar a lista de tarefas em um arquivo local (tarefas.json) automaticamente ao sair.
- Carregar a lista de tarefas ao iniciar, garantindo que o progresso não seja perdido.

 Tecnologias Utilizadas
- Linguagem: Python 
- Persistência de Dados: Módulo json (para salvar/carregar dados em um formato legível)
- Controle de Versão: Git e GitHub
